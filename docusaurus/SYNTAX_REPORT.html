3. MDX Frontmatter Default

Frontmatter is YAML metadata at the top of MDX files. This is a standard Docusaurus feature used to configure page metadata.

---
title: "Quick Start"
sidebar_position: 2
---

Common Frontmatter Fields

Field Purpose Source
title Page title displayed in browser tab and sidebar Default
sidebar_position Order of page in sidebar navigation Default
sidebar_label Custom label in sidebar (if different from title) Default
description SEO meta description Default

File Reference: docs/guides.mdx, docs/authentication.mdx

4. Tabs Component Default

The Tabs component is a built-in Docusaurus theme component that allows displaying content in switchable tabs. Perfect for showing code examples in multiple languages.

Import Statement

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

Usage Example

<Tabs>
  <TabItem value="http" label="HTTP" default>
    ```json
    { "title": "NDA Agreement" }
    ```
  </TabItem>
  <TabItem value="python" label="Python">
    ```python
    response = requests.post(url, json=payload)
    ```
  </TabItem>
</Tabs>

Tab Properties

Property Description
value Unique identifier for the tab (required)
label Display text shown on the tab button
default Marks this tab as the initially selected tab
💡 Design Decision

We use Tabs extensively to show API examples in HTTP, Python, Node.js, Java, and Bash. This allows developers to view code in their preferred language without page clutter.

5. Mermaid Diagrams Plugin

Mermaid support requires the @docusaurus/theme-mermaid plugin. This is NOT included by default and was added to our project.

Configuration Required

// docusaurus.config.js

markdown: {
  mermaid: true,
  format: 'detect',
},
themes: ['@docusaurus/theme-mermaid'],

Usage in MDX

```mermaid
flowchart TD
    A[Client] --> B[Send Request]
    B --> C{Validate API Key}
    C -->|Valid| D[200 OK]
    C -->|Invalid| E[401 Unauthorized]
```

Supported Diagram Types

Type Use Case
flowchart Process flows, decision trees (used for Authentication Flow)
sequenceDiagram API request/response sequences
stateDiagram Status transitions
erDiagram Entity relationships

Package: @docusaurus/theme-mermaid ^3.9.2

7. Sidebar Configuration Default

Sidebar structure is defined in sidebars.js. This is a standard Docusaurus configuration, but the structure and groupings are our custom design.

Configuration Structure

const sidebars = {
  docsSidebar: [
    {
      type: 'category',
      label: 'Essentials',
      collapsible: false,
      items: ['authentication', 'api-keys', ...],
    },
    // More categories...
  ],
};

Our Sidebar Structure

Category Pages Purpose
Essentials Authentication, API Keys, Sandbox, Best Practices Getting started fundamentals
Guides Quick Start, Workflows, Webhooks, Statuses Step-by-step tutorials
API Reference Request/Response, Errors, Rate Limits, etc. Technical specifications
💡 Design Decision

We set collapsible: false on all categories to keep the full navigation visible at all times, improving discoverability.

9. Theming & CSS Default + Custom

Docusaurus uses Infima as its CSS framework. We customize it via CSS variables in src/css/custom.css.

CSS Variable Customization

/* custom.css - Overriding Infima defaults */

:root {
  --ifm-color-primary: #2e8555;
  --ifm-color-primary-dark: #29784c;
  --ifm-code-font-size: 95%;
}

[data-theme='dark'] {
  --ifm-color-primary: #25c2a0;
}

Theming Breakdown

Feature Source Notes
Infima CSS Framework Default Bundled with classic preset
CSS Variables (--ifm-*) Default Standard customization method
Dark Mode Default Enabled via respectPrefersColorScheme
Primary Color (#2e8555) Custom Our brand green
Component CSS Modules Custom styles.module.css for Card, Section
